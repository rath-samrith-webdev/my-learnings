# Rust Learning

Learning Rust through the W3Schools Rust Tutorial.

## Learning Source

Primary curriculum:

* W3Schools Rust Tutorial
* Official Rust documentation for deeper clarification
* Practical exercises and projects for reinforcement

## Objective

Build a strong foundation in Rust before moving into advanced topics such as:

* Traits
* Generics
* Lifetimes
* Concurrency
* Async Rust
* Tokio
* Web development
* Systems programming

The W3Schools curriculum is the **starting foundation**, not the final destination.

# Learning Method

Every chapter follows:

```text
Read
 ↓
Understand
 ↓
Write examples
 ↓
Modify examples
 ↓
Solve exercises
 ↓
Build something small
 ↓
Explain the concept
 ↓
Review
```

Finishing a W3Schools chapter does **not** automatically mean the topic is mastered.

---

# Chapter Completion Criteria

A chapter is considered complete when:

* [ ] I read the chapter
* [ ] I understand the main concepts
* [ ] I wrote the examples myself
* [ ] I changed the examples without copying
* [ ] I completed exercises
* [ ] I can explain the topic
* [ ] I can identify common mistakes
* [ ] I applied the concept in a small program

# Mistakes

Record important misunderstandings in:

```text
mistakes.md
```

Especially:

* Borrow checker errors
* Ownership mistakes
* Type mistakes
* Unexpected behavior
* Concepts that were difficult to understand
* Solutions that finally made something click
