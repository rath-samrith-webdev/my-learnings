# Learning

My personal learning repository for tracking technical growth, practical skills, experiments, projects, and lessons learned.

The goal is not to collect courses or mark topics as "completed."

The goal is to turn learning into usable engineering ability.

---

## Learning Philosophy

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Build
  ↓
Break
  ↓
Debug
  ↓
Document
  ↓
Review
  ↓
Explain
  ↓
Improve
```

A topic is not considered learned simply because I finished reading or watching something.

I should be able to **use it, explain it, and solve problems with it**.

## Learning Rules

### 1. Practice beats consumption

Prefer:

```text
30% learning
70% practicing/building
```

over endlessly consuming tutorials.

### 2. Build before feeling ready

A project should expose what I don't understand.

### 3. Document mistakes

A mistake that gets documented becomes a future reference.

### 4. Don't learn everything at once

Keep:

* 1 primary learning focus
* 1–2 secondary topics
* 1 active project

### 5. Revisit difficult concepts

If something still feels unclear, return to it instead of simply moving forward.

### 6. Measure ability, not completion

"Finished Rust course" means little.

"I can build a Rust CLI without following a tutorial" means much more.
